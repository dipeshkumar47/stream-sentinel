# stream-sentinel 🛡️

> Real-time log streaming, semantic vector search, and AI-powered SRE incident analysis.

## Stack

- Apache Kafka (KRaft) — event streaming
- ChromaDB — vector database
- all-MiniLM-L6-v2 — local sentence embeddings
- LangGraph + Ollama — agentic reasoning
- FastAPI — REST + SSE API gateway
- FastMCP — Model Context Protocol server
